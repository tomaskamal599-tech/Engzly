# انجزلي (Engazly)

تطبيق أندرويد (Kotlin، من غير أي مكتبات خارجية) للتمرين والحياة الصحية بثيم بيكسل.

## اللي جواه
- **ميكس**: العادات والمهام في قايمة واحدة + تقدم اليوم بقلوب بيكسل + تمرين وسعرات النهارده.
- **عادات** و**مهام**: كل واحدة لوحدها (سلسلة أيام + آخر 7 أيام للعادات).
- **تمرين**: اكتب أو اختار أي رياضة، تايمر عد تنازلي + ستوب وتش، منبه بعد مدة (يرن والتطبيق مقفول)، وسجل تمارين.
- **وجبات**: صوّر الوجبة (أو اكتب وصفها) → تحليل تفصيلي: سعرات، بروتين، كربوهيدرات، سكر، سكر مضاف، ألياف، دهون، دهون مشبعة ومتحولة، كوليسترول، صوديوم، فيتامينات ومعادن، ومقارنة بهدفك: هل بيخدمه ولا لأ.
- **تنبيهات** (الجرس فوق): تنبيهات يومية أو مرة واحدة بنص مخصص ووقت من اختيارك + قوالب سريعة.
- **إعدادات** (الترس فوق): لغة عربي/إنجليزي، ثيم داكن/فاتح، الهدف وسعرات اليوم، مفتاح الـ API، الأذونات.

## تحليل الوجبات
بيستخدم Claude API. من الإعدادات الصق مفتاح الـ API (من console.anthropic.com). المفتاح بيتحفظ على الموبايل بس. الأرقام تقديرات من الصورة.

## البناء بدون لابتوب (GitHub Actions)
من Termux داخل فولدر المشروع:
```
git init
git add .
git commit -m "Engazly"
git branch -M main
git remote add origin https://github.com/<اسمك>/<الريبو>.git
git push -u origin main
```
بعد الـ push افتح تبويب **Actions** في الريبو، استنى شغل "Build APK"، وبعدين نزّل الملف **Engazly-APK** من آخر تشغيل. جواه `app-debug.apk` ثبّته على الموبايل.
